# 🎲 Random Task Generator

**Автор:** Яковлев Леонид Константинович 
**Дата создания:** 05.05.2026  
**Язык:** Python 3  
**GUI:** tkinter (стандартная библиотека)

## 📌 Описание
Графическое приложение для случайной генерации задач с возможностью фильтрации по категориям (учёба, спорт, работа), ручного добавления новых задач и сохранения истории в JSON-файл.

## 🚀 Как запустить
1. Убедитесь, что установлен Python 3.6+
2. Клонируйте репозиторий: `git clone <URL>`
3. Запустите файл: `python main.py`
4. Дополнительные зависимости не требуются.

## 🛠 Функционал
- ✅ Случайный выбор задачи из предопределённого списка
- 🔍 Фильтрация по типу задачи перед генерацией
- ➕ Добавление пользовательских задач с проверкой на пустоту
- 📜 Отображение истории генераций с временными метками
- 💾 Автосохранение/загрузка истории из `history.json`

## 🧪 Примеры использования / Тесты
| Действие | Ожидаемый результат |
|----------|---------------------|
| Нажать "Сгенерировать" | Выводится случайная задача, добавляется в историю |
| Выбрать фильтр "спорт" | Генерируется только задача из категории "спорт" |
| Ввести пустую строку и нажать "Добавить" | Появляется предупреждение `Задача не может быть пустой!` |
| Добавить задачу "Выучить Python" (тип: учёба) | Задача сохраняется, обновляется список фильтров |
| Закрыть и перезапустить приложение | История восстанавливается из `history.json` |

## 📁 Структура проекта
- `main.py` — основной код приложения
- `history.json` — файл истории (создаётся автоматически)
- `.gitignore` — исключения для Git
- `README.md` — документация
